# Founders photo

`thaakat-founders-yc.jpg` — the group shot rendered in the Founders section of the
landing page (`app/page.tsx`, `.founders-photo`).

Drop the Y Combinator photo here with exactly that filename. The layout crops to a
max height of 460px with `object-position: center 34%`, which keeps faces in frame;
if a different photo crops badly, adjust that value in `app/globals.css` rather than
pre-cropping the file.

Caption identifies who is who — update it in `app/page.tsx` if the photo changes.
